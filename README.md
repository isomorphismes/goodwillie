# Goodwillie

Reading notes on Thomas G. Goodwillie's calculus of homotopy functors, with an investigation of existing mathematical libraries and diagram systems that could help us explore it.

Start with the [notes index](notes/README.md).

The first pass covers homotopy cubes, excision, Taylor towers, cross-effects, derivatives, and convergence. It also records concrete source files in existing formalization projects and examines the diagram ideas associated with Bob Coecke, Ross Duncan, Aleks Kissinger, and their collaborators.

The question guiding this notebook is: **which mathematical relationships can we already express, check, manipulate, and see using existing work?** The comparison keeps reusable definitions, proved results, diagram operations, and proposed experiments explicit.
